# Anki AI批量制卡插件需求文档

## 一、基础背景

适配最新版Anki（26.08.1，PyQt6环境），开发一款AI辅助批量生成卡片插件，完全复用Anki本地已有资源，无需自定义模板，降低使用门槛。

## 二、核心功能需求

### 1. AI接口配置管理

1. 提供可视化配置窗口，可直接在插件界面修改：API密钥、接口请求地址、模型名称、请求超时时间，配置自动保存，无需手动编辑json文件。
2. 新增AI接口连通性测试功能，发送极简测试请求，校验密钥、地址、模型有效性，异常时返回具体报错信息。

### 2. 复用Anki原生资源

1. **笔记模板选择**：自动读取Anki本地所有已存在的笔记类型（Basic、自定义美化模板、第三方模板等），下拉框选择，AI严格匹配对应模板的字段生成内容，不新建多余笔记模型。
2. **目标牌组选择**：自动加载Anki全部牌组列表，可自主指定生成卡片的导入目标牌组，不再默认导入当前牌组。

### 3. AI卡片生成与预处理

1. 用户输入自然语言制卡需求，AI按照选中模板的字段结构生成卡片数据。
2. 自动过滤全部字段为空的无效卡牌，仅保留有效卡片。
3. 生成后提供预览表格，支持手动删除不需要的卡片，确认后再执行导入。

### 4. 卡片导入功能

将筛选后的卡片，按照选中的笔记模板，批量导入到指定牌组，卡牌属性、样式、复习规则与手动创建的卡片完全一致。

## 三、界面与交互要求

1. 主界面布局简洁：配置测试区、模板选择区、牌组选择区、需求输入框、功能操作按钮分区清晰。
2. 操作流程：配置AI信息→测试连通性→选择模板&牌组→输入需求→生成卡片→预览删卡→导入目标牌组。
3. 操作反馈：生成数量提示、导入成功提示、错误弹窗提示，交互友好。

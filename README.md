# AICard - Anki AI 批量制卡插件

`AICard` 是一款为 Anki（兼容 26.08.1+ / PyQt6 环境）开发的 AI 辅助批量制卡插件。它旨在复用用户本地已有的牌组和笔记模板，通过兼容 OpenAI 标准的大模型接口，将零散的学习材料快速转化为格式规范的 Anki 卡片。

## 核心功能

*   **复用本地资源**：自动读取 Anki 本地的笔记类型（Templates）与牌组列表。AI 会严格根据所选模板的字段结构生成内容，无需手动修改或创建新的笔记类型。
*   **可视化配置与测试**：提供直观的配置界面，支持自定义 API Key、Base URL、模型名称和超时时间。内置连通性测试功能，即时反馈接口可用性。
*   **双栏交互界面**：
    *   **左侧（输入与预览）**：支持直接粘贴文本或上传 `.txt` / `.md` 文件；生成后提供带复选框的表格预览，支持批量删除、全选/反选。
    *   **右侧（编辑与导入）**：动态渲染当前模板的所有字段，选中表格行即可直接在右侧编辑微调；支持自定义标签并一键导入指定牌组。
*   **兼容多平台大模型**：支持 OpenAI 官方接口，以及任意兼容 OpenAI 格式的第三方大模型 API（如 DeepSeek、月之暗面 Moonshot、通义千问、或本地运行的 Ollama 等）。

## 安装与配置

### 1. 开发模式安装（推荐开发人员）
将整个 `AICard` 文件夹移动或链接到 Anki 的插件数据目录下：
*   **Windows**: `%APPDATA%\Anki2\addons21\AICard`
*   **macOS**: `~/Library/Application Support/Anki2/addons21/AICard`
*   **Linux**: `~/.local/share/Anki2/addons21/AICard`

重启 Anki 即可在 **工具 -> AI 生成卡片 (AICard)** 菜单中找到该插件。

### 2. 打包为 `.ankiaddon` 发布
在项目根目录下，使用 Python 运行打包脚本：
```bash
python build.py
```
运行后会在目录下生成 `AICard.ankiaddon` 文件。直接双击该文件或将其拖入 Anki 窗口中即可完成安装。

## 使用指南

1.  **打开界面**：点击 Anki 菜单栏的 **工具** -> **AI 生成卡片**，或使用快捷键 `Ctrl + Shift + A`。
2.  **配置 AI 接口**：首次使用请点击界面右上角的 **⚙ AI 配置**，填写你的 API Key、Base URL 和模型名称（例如 `gpt-4o-mini` 或 `deepseek-chat`）。点击 **测试连通性** 确保配置正确后保存。
3.  **准备环境**：在右侧选择你希望导入的**目标牌组**和**笔记类型**。
4.  **输入学习材料**：在左侧输入框内粘贴学习文本，或点击 **选择文件** 载入本地的文本文件。
5.  **生成卡片**：点击 **生成卡片** 按钮，等待 AI 处理。生成成功后，左下角表格将展示预览结果。
6.  **调整与删改**：
    *   在表格中点击某一行，右侧对应的字段编辑框将载入详细内容，可直接在右侧修改，修改会自动同步回表格。
    *   对于不需要的卡片，取消勾选或选中后点击 **删除选中**。
7.  **导入**：在右下角输入框内添加标签（空格分隔），确认无误后点击 **添加到牌组**，卡片将被安全地导入到你的本地 Anki 集合中。

---

## 注意事项

*   **字段匹配**：AI 会尽量将提炼的内容填入你所选择的笔记类型的对应字段中。建议选择字段逻辑清晰的模板（例如最基础的“问答题”或“问答/背面解释”等）。
*   **网络提示**：使用第三方 API 时，请确保网络通道畅通。如遇超时，可在配置窗口中适当调大超时时间（默认 60 秒）。
